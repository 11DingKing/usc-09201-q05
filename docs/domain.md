# 森林经营方案年历领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 不变量

1. **只追加，不改旧账。** 任何状态变化都是一条不可变事件，含事件序号、发生时间、操作者与载荷。旧计划不得就地修改；拆分、延期、换版、禁作期修订均以新事件表达。
2. **批准版本是作业前提。** 任务只能排到方案的当前批准版本；换版后旧版本任务冻结，新动作必须以 `source_task_id` 承接，版本链可回溯。
3. **前置关系决定可执行性。** 前置任务完工（或被拆分后其全部承接子任务完工）后，后续任务才进入可执行清单。
4. **生态限制优先。** 限制按方案、地块、作业类型匹配；命中当日禁作期时作业暂停且不计逾期，实际阻断天数顺延到期日。禁作期提前通过“新通知废止旧通知”表达，两个日期区间的并集构成抵扣依据，旧通知仍在历史中。
5. **延期须审批。** 延期申请在决行前为未决状态，期间任务不计逾期、不得拆分或取消；批准可跨年度，驳回则保留原到期日。
6. **回执唯一且幂等。** 回执号全局唯一；重复提交（含命令重试）不得产生第二次影响。命令以幂等键去重，重试直接返回首次结果。
7. **重启不漂移。** 可执行清单、逾期依据、提醒与未决审批均由持久化事件配合当日业务时间重放得出，不依赖进程内定时器；每个未结任务至多一条活动提醒。
8. **判定须有依据。** 逾期结论必须同时给出原始窗口、批准延期、禁作期抵扣（含政策文号与事件序号）、完成量、责任人交接链与回执，便于年度检查复核。
